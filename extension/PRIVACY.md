# FlightScout Privacy Policy

_Last updated: 2026-09-15_

FlightScout is a Chrome extension that captures and accumulates flight search results shown on Skyscanner search pages so users can compare them across multiple searches.

## Data FlightScout collects

FlightScout reads flight result data that is already visible on Skyscanner search result pages (dates, times, prices, durations, stops, and airlines) using a content script. This data is **website content**, not personal data about the user.

FlightScout does not collect, request, or have access to:

- Personally identifiable information (name, email, address, ID numbers)
- Health information
- Financial or payment information
- Authentication credentials (passwords, PINs)
- Personal communications
- Location data
- Web browsing history
- Keystrokes, mouse activity, or other user activity monitoring

## How data is stored

All captured flight data is stored locally on the user's device using the `chrome.storage.local` API. FlightScout does not send any data to external servers, and does not use any remote or third-party analytics service.

## Data sharing

FlightScout does not sell, transfer, or share collected data with any third party. Data never leaves the user's browser except when the user explicitly chooses to export it (Copy table / Export CSV).

## Data retention and deletion

Captured flight data remains in local browser storage until the user clicks **Clear** in the extension popup, or uninstalls the extension.

## Changes to this policy

Any changes to this privacy policy will be reflected in this document with an updated "Last updated" date.
